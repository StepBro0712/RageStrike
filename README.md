# RageStrike

FPS в духе Counter-Strike 2 со **встроенными rage-читами как игровыми фичами**. Матч против ботов по правилам CS (закупка, экономика, смена сторон), читы настраиваются в своём меню на **Del**. Unreal Engine 5.8, весь геймплей на C++ без блюпринтов.

## Скачать и играть

Проще всего — взять собранную игру из [Releases](../../releases): распакуй zip и запусти `RageStrike.exe`. Ничего устанавливать не нужно.

## Что внутри

- **Лобби**: игра запускается в лобби, персонаж стоит на карте, матч начинается по кнопке. Из матча можно вернуться в лобби, не закрывая игру
- **Карты**: Dust 2, Mirage, процедурная арена (выбор в меню)
- **Арсенал CS**: 20 стволов от Glock до AWP с ценами, уроном, скорострельностью и паттернами отдачи как в CS + нож
- **Гранаты**: HE, флешка, дым (боты сквозь него не видят), молотов/зажигалка
- **Хитбоксы по костям**: голова, грудь, живот и конечности со своим уроном, шлем спасает от хедшота
- **Механики CS**: контр-стрейф, тихая ходьба на Shift, замедление от попаданий, броня и шлем, падение урона с дистанцией, экономика с лосс-бонусами, killfeed, радар
- **Раунды**: число раундов, время раунда и время закупки задаются перед матчем, смена сторон в середине
- **Читы**: своё меню с разделами Rage / Legit / Visuals / Misc, ползунками и конфигами по именам
- **Настройки**: перебинд управления, прицел с превью и раздельными каналами цвета, обзор, яркость, положение оружия по трём осям, раздельная громкость
- **Сетевая игра**: хост LAN / подключение по IP из меню

## Управление

| Клавиша | Действие |
|---|---|
| WASD / мышь | движение и камера |
| ЛКМ / ПКМ | стрельба / оптика (с гранатой — подкат) |
| 1 / 2 / 3 / 4 | основное / пистолет / нож / гранаты |
| B | закупка (цифры — навигация, 0 — назад) |
| G | выбросить оружие |
| R | перезарядка |
| Shift | тихая ходьба |
| Ctrl | присед |
| F | осмотр оружия |
| V | вид от третьего лица |
| Tab | счёт |
| Del / Insert | меню читов |
| Esc | меню игры |

Движение, прыжок, присед, тихая ходьба, огонь и перезарядка **переназначаются** в настройках, там же есть возврат к раскладке по умолчанию.

## Читы

Открываются на **Del** или **Insert**. Настройки сохраняются в именованные конфиги (`Saved/Cheats/*.ini`) и загружаются обратно.

- **Rage** — триггербот с конусом срабатывания, минимальный урон (в стену чит не стреляет), шанс попадания, упреждение с глубиной в тиках, бэктрек, двойной выстрел, бинд на второй порог урона, анти-аим с режимами, бесконечные деньги (только в одиночной игре), бессмертие, скорость и распрыжка
- **Legit** — аимбот с плавной подводкой, временем реакции и условием включения, silent aim, выбор хитбокса, контроль отдачи в процентах
- **Visuals** — ESP: рамка, заливка силуэта, скелет, полоса здоровья, дистанция, линия к цели, метка упреждения, выбор цвета; chams — модели противников видно сквозь стены
- **Misc** — автострейф в воздухе, мгновенная смена оружия, звук попадания, лог урона и причин промаха

## Сборка из исходников

В репозитории только код: ассеты (модели с Fab, импортированные карты) по лицензии распространять нельзя, поэтому папки `Content/` и `Plugins/` не выложены — без них проект из исходников не соберётся один в один. Код лежит в `Source/RageStrike/`:

- `RSCharacter.*` — игрок: движение CS, стрельба, отдача, инвентарь, читы, вьюмодель
- `RSWeaponData.*` — таблица всего арсенала (цены, урон, отдача)
- `RSGrenade.*` / `RSFireZone.*` — гранаты и огонь молотова
- `RSBot.*` — ИИ ботов
- `RSGameMode.*` / `RSGameState.*` — раунды, экономика, killfeed
- `RSHUD.*` — весь интерфейс в стиле CS2 (Canvas)
- `RSArena.*` / `RSMaps.*` — загрузка карт и процедурная арена
- `RSMenu.*` — меню игры: лобби, правила матча, настройки, перебинд, прицел (Slate)
- `RSCheatMenu.*` — меню читов с разделами, ползунками и конфигами (Slate)
- `RSBinds.*` — перебинд управления и настройки прицела
- `RSLoadingScreen.*` — экран загрузки с логотипом

Требования: Unreal Engine 5.8, Visual Studio 2026 с workload «Game development with C++».
