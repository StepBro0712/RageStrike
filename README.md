# RageStrike

FPS в духе Counter-Strike 2 со **встроенными rage-читами как игровыми фичами**. Матч против ботов по правилам CS (24 раунда, закупка, экономика), читы включаются клавишами F1–F7. Unreal Engine 5.8, весь геймплей на C++ без блюпринтов.

## Скачать и играть

Проще всего — взять собранную игру из [Releases](../../releases): распакуй zip и запусти `RageStrike.exe`. Ничего устанавливать не нужно.

## Что внутри

- **Карты**: Dust 2, Mirage, процедурная арена (выбор в стартовом меню)
- **Арсенал CS**: 20 стволов от Glock до AWP с ценами, уроном, скорострельностью и паттернами отдачи как в CS + нож
- **Гранаты**: HE, флешка, дым (боты сквозь него не видят), молотов/зажигалка
- **Механики CS**: контр-стрейф, тихая ходьба на Shift, замедление от попаданий, броня и шлем, падение урона с дистанцией, экономика с лосс-бонусами, killfeed, радар
- **Раунды**: 24 раунда, смена сторон после 12, победа при 13, закупка между раундами
- **Rage-читы**: aimbot, ESP/wallhack, triggerbot, norecoil, speedhack+bhop, silent aim, godmode
- **Сетевая игра**: хост LAN / подключение по IP из стартового меню

## Управление

| Клавиша | Действие |
|---|---|
| WASD / мышь | движение и камера |
| ЛКМ / ПКМ | стрельба / оптика (с гранатой — подкат) |
| 1 / 2 / 3 / 4 | основное / пистолет / нож / гранаты |
| B | закупка (цифры — навигация, 0 — назад) |
| G | выбросить оружие |
| R | перезарядка |
| Shift | тихая ходьба |
| Ctrl | присед |
| F | осмотр оружия |
| V | вид от третьего лица |
| Tab | счёт |
| Esc | меню |

## Rage-читы

| Клавиша | Чит |
|---|---|
| F1 | Aimbot |
| F2 | ESP / WH (боксы, HP, снаплайны + враги на радаре) |
| F3 | Triggerbot |
| F4 | NoRecoil / NoSpread |
| F5 | Speedhack + авто-BHop |
| F6 | Silent Aim |
| F7 | GodMode |

## Сборка из исходников

В репозитории только код: ассеты (модели с Fab, импортированные карты) по лицензии распространять нельзя, поэтому папки `Content/` и `Plugins/` не выложены — без них проект из исходников не соберётся один в один. Код лежит в `Source/RageStrike/`:

- `RSCharacter.*` — игрок: движение CS, стрельба, отдача, инвентарь, читы, вьюмодель
- `RSWeaponData.*` — таблица всего арсенала (цены, урон, отдача)
- `RSGrenade.*` / `RSFireZone.*` — гранаты и огонь молотова
- `RSBot.*` — ИИ ботов
- `RSGameMode.*` / `RSGameState.*` — раунды, экономика, killfeed
- `RSHUD.*` — весь интерфейс в стиле CS2 (Canvas)
- `RSArena.*` / `RSMaps.*` — загрузка карт и процедурная арена
- `RSMenu.*` — стартовое меню и меню паузы (Slate)

Требования: Unreal Engine 5.8, Visual Studio 2026 с workload «Game development with C++».
